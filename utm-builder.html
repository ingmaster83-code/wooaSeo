UTM 링크 생성기 (캠페인 URL 빌더)

광고·뉴스레터·SNS 캠페인용 링크에 utm_source, utm_medium, utm_campaign, utm_term, utm_content, utm_id 를 붙여 줍니다. 여러 URL 에 한 번에 적용하고, 값을 소문자와 밑줄로 정리하며, 이미 있는 UTM 덮어쓰기, # 앞 쿼리 위치, GA4 채널 분류에 맞지 않는 medium 같은 흔한 실수를 알려 줍니다.

사용 예시

✅ URL 2개에 UTM 을 붙였습니다

입력 — 대상 URL (한 줄에 하나 — 여러 개면 한꺼번에 UTM 을 붙입니다)

https://example.com/pricing
https://example.com/blog/launch?ref=home#plans

결과 — UTM 이 붙은 URL

https://example.com/pricing?utm_source=newsletter&utm_medium=email&utm_campaign=fall_sale_2026&utm_content=header_button
https://example.com/blog/launch?ref=home&utm_source=newsletter&utm_medium=email&utm_campaign=fall_sale_2026&utm_content=header_button#plans

결과 — 적용된 매개변수

매개변수 | 값 | 인코딩
utm_source | newsletter | —
utm_medium | email | —
utm_campaign | fall_sale_2026 | —
utm_content | header_button | —

이 도구로 할 수 있는 일

마케팅 링크의 유입을 GA4 에서 정확히 구분하도록 UTM 을 올바르게 붙입니다. URL 은 서버로 전송되지 않습니다.

  • 매개변수: utm_source, utm_medium, utm_campaign(필수), utm_term, utm_content, utm_id(선택)
  • 일괄 처리: 한 줄에 URL 하나씩 여러 개 입력, 기존 쿼리와 # 조각 유지
  • 값 정리: 소문자 + 공백을 _ 또는 - 로 바꾸거나 입력 그대로 사용, 한글·특수문자 퍼센트 인코딩
  • 점검: 필수 값 누락, GA4 기본 채널 그룹과 맞지 않는 medium, 대문자 혼용, 기존 utm_* 중복, 2,000자 초과
  • 팁: 사이트 내부 링크에는 UTM 을 쓰지 말고, 팀의 이름 규칙을 정해 두기

💡 Tips

  • utm_medium 은 cpc, email, social, display, affiliate, referral 처럼 GA4 가 인식하는 값을 쓰면 채널 분류가 정확해집니다.
  • GA 는 대소문자를 구분합니다. 'Email' 과 'email' 이 따로 집계되지 않게 항상 소문자로 통일하세요.
  • UTM 은 # 앞의 쿼리 문자열에 있어야 서버와 분석 도구에 전달됩니다.

자주 묻는 질문

UTM 을 붙이면 SEO 에 불리한가요?

검색 엔진은 UTM 이 붙은 URL 도 같은 페이지로 보고 canonical 로 묶습니다. 단, 사이트 내부 링크에는 쓰지 마세요. 유입 출처가 덮어써집니다.

utm_id 는 무엇인가요?

GA4 에서 캠페인 ID 와 비용 데이터를 가져온 광고와 연결할 때 쓰는 매개변수입니다. 광고 플랫폼 연동이 없다면 비워 두어도 됩니다.

입력한 데이터가 서버로 전송되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 입력한 내용은 서버로 전송되거나 저장되지 않습니다. 개인정보나 사내 설정값, API 키가 들어 있는 데이터도 안심하고 붙여 넣을 수 있습니다.
