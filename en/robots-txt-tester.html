robots.txt Tester (Crawl Allow / Block Check)

Paste robots.txt and a list of URLs to see whether the chosen crawler (Googlebot, Bingbot, Yeti, GPTBot ...) may fetch each one, judged by RFC 9309 rules (longest match wins, Allow wins ties, * and $) with the line number of the deciding rule. Noindex directives, misplaced rules and blocked CSS / JS are flagged too.

Example

✅ 3 of 7 blocked - group "*"

Input — robots.txt content

User-agent: *
Disallow: /admin/
Disallow: /search
Disallow: /*.pdf$
Allow: /admin/public/

User-agent: Googlebot
Disallow: /private/
Crawl-delay: 5

User-agent: AhrefsBot
User-agent: SemrushBot
Disallow: /

Sitemap: https://example.com/sitemap.xml

Input — URLs or paths to test (one per line)

/
/admin/
/admin/public/page.html
/search?q=seo
/docs/guide.pdf
/private/data
https://example.com/blog/post-1

Result — Verdict per URL

URL | Verdict | Deciding rule | Rule length
/ | ✅ allowed | no matching rule → allowed | 0
/admin/ | ⛔ blocked | Disallow: /admin/ (line 2) | 7
/admin/public/page.html | ✅ allowed | Allow: /admin/public/ (line 5) | 14
/search?q=seo | ⛔ blocked | Disallow: /search (line 3) | 7
/docs/guide.pdf | ⛔ blocked | Disallow: /*.pdf$ (line 4) | 6
/private/data | ✅ allowed | no matching rule → allowed | 0
https://example.com/blog/post-1 | ✅ allowed | no matching rule → allowed | 0

Result — Applicable rules

Type | Path | Line
Disallow | /admin/ | 2
Disallow | /search | 3
Disallow | /*.pdf$ | 4
Allow | /admin/public/ | 5

What this tool does

Check that robots.txt blocks only what you intend before you deploy it. The file and URLs are not uploaded.

  • Verdict: longest path match wins, Allow wins ties, * wildcard and trailing $, case-sensitive paths
  • Group selection: the most specific User-agent group for the crawler (groups are not merged), stacked User-agent lines, * fallback
  • Crawlers: Googlebot, Googlebot-Image, Bingbot, Yeti, Daumoa, GPTBot, ClaudeBot, CCBot, AhrefsBot, or your own
  • Checks: Disallow: / blocking everything, Noindex directive, rules before a User-agent, non-standard directives, Sitemap format, blocked CSS / JS, duplicate groups and Crawl-delay

💡 Tips

  • Once you add a group for a specific bot, the * group no longer applies to it; repeat the rules you need.
  • Blocking in robots.txt does not remove a URL from search results; use a noindex meta tag or X-Robots-Tag to prevent indexing.
  • AI training crawlers (GPTBot, ClaudeBot, CCBot ...) are blocked with their own User-agent groups.

Frequently Asked Questions

Is it the same as Google's robots.txt tester?

It follows RFC 9309 and Google's published rules, but results can differ from the official Search Console tool; confirm important changes there.

Does it support the Naver and Daum crawlers?

Yes: choose Yeti (Naver) or Daumoa (Daum). Without a group for that name, the * group applies.

Is my data uploaded to a server?

No. Everything is processed inside your browser; what you enter is never sent to or stored on a server, so you can safely paste data containing personal information, internal settings or API keys.
